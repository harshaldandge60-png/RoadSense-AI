# Model Training

This folder contains the code used to train the RoadSense AI machine learning model.

## Planned Pipeline

1. Collect sensor data
2. Clean the data
3. Filter noise
4. Segment sensor signals
5. Extract features
6. Train the model
7. Evaluate the model
8. Save the trained model

## Road Classes

- Normal
- Pothole
- Speed Breaker
- Rough Road
- Gravel
